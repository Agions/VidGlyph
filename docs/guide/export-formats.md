# 导出格式说明

SubLens 支持多种常见的字幕与文本导出格式。

---

## 常用导出格式

| 格式 | 扩展名 | 适用场景 |
|:-----|:-------|:---------|
| SubRip Subtitle | `.srt` | 最通用的字幕格式，适配几乎所有播放器与视频剪辑软件 |
| WebVTT | `.vtt` | HTML5 Web 网页视频播放器标准字幕格式 |
| 纯文本 | `.txt` | 提取纯字幕文本，用于台词整理与大模型二次加工 |
| JSON 数据 | `.json` | 结构化格式，包含置信度、时间戳毫秒与归一化 ROI 坐标 |
