# ROI 区域选择

SubLens 提供了交互式 HTML5 Canvas / SVG 叠加图层，支持用户通过 8 点手柄（Handles）精准框选视频中的硬字幕区域。

---

## 8 点手柄框选与坐标归一化

1. **自由拖拽与拉伸**：在视频预览画面上鼠标拖拽选框中心可平移选区；拖拽四周及四角 8 个控制手柄可调整宽高。
2. **坐标归一化 (0.0 ~ 1.0)**：选区坐标在底层自动计算为相对比例（`x, y, width, height` 为 0.0 ~ 1.0），无论视频窗口拉伸缩放或屏幕分辨率变化，都能准确映射到视频原始分辨率帧上。
3. **裁剪识别**：识别引擎仅对选区内画面进行 OCR 处理，有效过滤视频背景噪声并大幅提升准确度与效率。
