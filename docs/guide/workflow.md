## 四步工作流

```
1. 导入视频 ──► 2. 8点手柄框选 ROI ──► 3. 选择离线/云端模式开始提取 ──► 4. 预览与导出
```

### 1. 导入视频
点击顶部工具栏的“导入视频”按钮或直接将视频文件拖拽至视频播放器区域。支持 MP4, MKV, AVI, MOV, WebM 等文件。

### 2. 8点手柄框选 ROI
在左侧视频预览图层上，使用 8 点手柄交互式调整、拉伸和拖拽框选硬字幕的有效区域，支持点击“自动定位选区”智能探测推荐。

### 3. 选择模式与开始提取
在顶部选择“离线模式”或“云端 API”模式。若使用云端 API 模式，需在设置中配置 API Key。点击“开始提取字幕”，系统将自动调度抽帧与识别。

### 4. 预览与导出
在右侧面板实时查看字幕时间轴列表，支持点击卡片 Seek 视频播放位置、AI 智能润色错别字、内联编辑文本、调整时间码，并一键导出为 SRT、VTT 或 TXT 格式。
